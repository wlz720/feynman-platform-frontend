# 夏日水域主题 · 设计 Token 与组件规范（第一期）

> 只改视觉层。路由、数据结构、交互逻辑一律未动，其余页面的结构也保持原样，仅通过下面的 token 自动换色。
> 代码位置：`src/index.css` 的 `:root`（变量名沿用旧版，所以全站引用不会断）。

## 3. 圆角 / 阴影 / 字体

- 圆角：`--radius-sm 12px` · `--radius-md 16px` · `--radius-lg 20px` · `--radius-xl 26px`；按钮统一胶囊 `999px`。
- 阴影（只为"轻轻浮起"，不再是重阴影）：`--shadow-xs 0 1px 2px rgba(51,71,91,.04)` · `--shadow-sm 0 6px 18px rgba(51,71,91,.06)` · `--shadow-md 0 14px 32px rgba(51,71,91,.08)` · `--shadow-lg 0 26px 56px rgba(51,71,91,.10)`。
- 字体：正文沿用系统无衬线；标题与数字用 `--font-serif`（`"Songti SC", SimSun, Georgia, "Times New Roman", serif`），形成杂志感对比。

## 4. 夏夜海面（只给 3D 三页的"场景外控件"用，暂未应用）

`--night-bg #0E1E2E`、`--night-surface rgba(14,30,46,.78)`、`--night-line #7EC8E3`、`--night-ink #EAF4FA`、`--night-ink-light #9FBCCC`。3D 场景本体（星空、银河、地球贴图）保持原样不动。

## 5. 组件规范

- **按钮**：胶囊形；主按钮实底 `#35779C`（hover `#2F6A8C`，白字对比约 4.9:1）；次按钮白底 + `--line` 描边；复述按钮海沫绿 `#3F9C81`（hover `#368B72`）；测评按钮海水蓝 `#35779C`；危险 `#C36154`。hover 上浮 1px，并加一圈向外扩散的浅蓝 ring 模拟涟漪。
- **输入框**：白底、1px `--line` 细描边、圆角 14px；聚焦时 4px 浅蓝 ring（`rgba(126,200,227,.35)`）。
- **卡片**：白底 + 1px 细边 + `--shadow-sm`，去掉厚阴影；卡片内分隔线由虚线改实线。
- **状态胶囊**：浅底 + 描边 + 压深文字，例如「已掌握」= 底 `#EFF9F5` / 边 `#CBE9DF` / 字 `#2E7A62`。
- **水位线进度条** `.wave-track` + `.wave-fill`：8px 高胶囊轨道，填充上缘用 repeat-x 的 SVG mask 切出波浪（`40px × 100%` 平铺）；填充渐变 `#8FD0E5 → #5AA8C9`。
- **海浪气泡**（AI 助手）：SVG `mask-image`（`viewBox 0 0 100 100`，`mask-size: 100% 100%`），上缘平直、下缘两道缓和波浪（幅度约 14%）；AI 气泡浅蓝水彩多层渐变 + 左下两颗涟漪圆点作"尾巴"；用户气泡白底细描边、右侧对齐。
- **风铃 / 金鱼 / 海浪线**：`SummerDecor.jsx` 三个纯内联 SVG 组件（`WindChime` 6.5s 轻微摆动、`Goldfish` 水彩珊瑚色、`WaveLine` 三次贝塞尔正弦线），零外部图片。

## 6. 装饰预算与动效

- 每屏装饰 ≤ 3 处；移动端（≤760px）隐藏风铃等顶部装饰，避免压字。
- 全部动效在 `@media (prefers-reduced-motion: reduce)` 下降级：动画/过渡压到 0.001ms，风铃停止摆动。

## 7. 与设计稿的一处偏差（需要你确认）

设计稿给的次要文字色 `#7A93A6` 在白底上只有约 3.3:1，达不到你要求的 4.5:1。处理方式：

- 承载文字的 `--ink-light` / `--muted` 压深为 `#5B7487`（白底约 4.9:1）；
- 原 `#7A93A6` 保留为 `--ink-faint`，只用于装饰线条和占位图形；
- 主色文字统一用 `--primary-ink #2F6484`。

这样色相不变、明度略降，整体观感仍是低饱和高明度，但所有正文/标签都过 4.5:1。
